What this found

  • Routing: deep links need a real workaround (a custom 404 redirect trick), not free — costs a visible flicker.
  • Offline caching: works, but only for exactly what's explicitly precached, not "the site works offline."
  • Pyodide: real ~14.5MB upfront cost, genuinely works after that — the ceiling is measured live, not asserted.
  • Scheduled updates: take real minutes, not seconds — schedule slip plus deploy time, both measured directly.
  • Size limits: irrelevant in practice for a project this size — a small fraction of a percent of any real ceiling.
