Write-up

All three of these run entirely in the browser — no server, no build step, no API call. That's the baseline every later experiment here builds on: if plain JS/DOM/Canvas works, the interesting question for each next test is what stops working (or gets expensive) as the demo gets heavier — Pyodide's numeric ceiling, Actions round-trip latency, offline caching, and so on.

The canvas demo was originally a passive auto-animating dot. It technically worked (verified by reading the drawn pixel data directly), but a small shape drifting slowly across an empty box turned out to be easy to mistake for broken — twice. Replaced with click/drag drawing instead: tying the effect directly to visitor input removes the ambiguity, and it's arguably a more honest test of "does canvas work" than a loop nobody's watching.
